# PSForge Desktop 2.0 Milestones

## Phase 0: Planning And Design Direction

Outcome: a clear 2.0 product direction before implementation begins.

- Confirm the 2.0 north star.
- Define the target workspace layout.
- Inventory existing 1.x surfaces that map into the new shell.
- Decide which ideas are must-have, should-have, and later.
- Produce rough wireframes for the unified workbench, Script Intelligence panel, Run Center, and command library.

## Phase 1: Workspace Shell

Outcome: the app feels like one cohesive desktop workbench.

- Introduce the main workbench frame.
- Add left rail navigation.
- Reposition existing script workspace into the new frame.
- Add right inspector placeholder.
- Add bottom panel placeholder.
- Preserve existing script tab, save, recovery, and account behavior.

## Phase 2: Script Intelligence

Outcome: the active script becomes easier to understand and safer to run.

- Surface existing script analysis in a right inspector.
- Show parameters, modules, risks, placeholders, and checklist state.
- Merge validation summary into the inspector.
- Add clear run-readiness states.
- Add contextual actions for header generation, placeholder replacement, and validation fixes.

## Phase 3: Command And Workflow Library

Outcome: automation discovery feels curated and visually stronger.

- Add platform pack grouping.
- Improve command cards with richer metadata.
- Add compact and expanded modes.
- Improve search grouping.
- Promote favorites and recently used commands.
- Explore workflow cards that insert complete starter scripts.

## Phase 4: Run Center

Outcome: script execution becomes a first-class, safer desktop workflow.

- Build a dedicated Run Center view.
- Improve parameter preview and environment profiles.
- Show dry-run, report-only, transcript, and elevation choices together.
- Improve run history layout.
- Add transcript and artifact actions.
- Add runbook export from run history.

## Phase 5: Contextual AI

Outcome: AI helps from the place where the user is already working.

- Add editor selection actions.
- Add validation issue actions.
- Add run failure explanation.
- Add AI recommendations in the inspector.
- Keep Pro upgrade flow clear and non-disruptive.

## Phase 6: Visual And Desktop Polish

Outcome: 2.0 feels premium, stable, and Windows-native.

- Refine color, density, typography, and elevation.
- Add purposeful empty states and platform visuals.
- Improve splash/loading/update surfaces.
- Add command palette.
- Improve keyboard shortcuts.
- Tighten responsive behavior for smaller desktop windows.

## Candidate 2.0 Beta Criteria

- Existing 1.x script editing, save, open, recovery, and Pro auth still work.
- Main workbench shell is stable.
- Script Intelligence panel is useful without requiring AI.
- Command library is easier to browse than 1.x.
- Run Center provides a clearer preflight and history experience.
- No major regression in desktop packaging or update flow.
