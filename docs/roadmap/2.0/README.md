# PSForge Desktop 2.0 Planning

PSForge Desktop 2.0 is planned as a major refinement of the 1.x product, not a full rewrite. The goal is to make the existing power feel clearer, safer, more polished, and more desktop-native.

## North Star

PSForge Desktop 2.0 is a refined PowerShell automation workbench for Windows admins: faster to start, safer to run, clearer to review, and more polished in every workspace.

## 2.0 Priorities

1. Unified desktop workspace shell
2. Script Intelligence panel
3. Richer command and workflow library
4. Run Center for safer execution
5. Contextual AI actions
6. Command palette
7. Polished Windows desktop experience
8. Stronger onboarding by job-to-be-done

## Product Stance

2.0 should not chase visual spectacle. It should feel premium because it is organized, fast, reliable, and confident. The app should preserve the practical developer-tool tone from 1.x while making each major workflow easier to understand and more satisfying to use.
