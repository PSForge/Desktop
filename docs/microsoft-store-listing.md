## Description

PSForge Desktop is a modern PowerShell automation workspace for Windows admins, IT teams, and power users who want a better place to create, review, run, and reuse scripts.

Instead of juggling scattered `.ps1` files, browser tabs, notes, and one-off snippets, PSForge gives you one focused desktop workbench for day-to-day PowerShell automation. Open and save local scripts, work across tabs, recover drafts, build scripts from guided starters, review script readiness, and keep common admin workflows close at hand.

PSForge Desktop is designed around practical Windows administration. Use the script editor when you want direct control, the Library when you want a faster starting point, the GUI builder when you want guided task scaffolding, and the Log Troubleshooter when you need help turning errors into next steps.

Key workflows include:

- Writing and editing PowerShell scripts in a desktop-first workspace.
- Opening, saving, and recovering local `.ps1` files.
- Starting from curated script templates for Windows and Microsoft 365 administration.
- Reviewing parameters, module usage, warnings, and readiness before running scripts.
- Using guided builders for common automation tasks.
- Keeping local run context, script notes, and troubleshooting close to the editor.
- Using AI-powered script assistance and log troubleshooting with PSForge Pro.

PSForge is built for people who want the speed of PowerShell with a cleaner, safer, and more organized desktop workflow.

## Official Microsoft Notes

- Store listing requires a description and at least one screenshot; Microsoft recommends multiple images.
- Description limit: 10,000 characters.
- Short description limit: 1,000 characters, with best results under 270 characters.
- Product features limit: 20 features, 200 characters per feature.
- Screenshots: 1 required, 4+ recommended, 10 maximum.
- Store logos: 1:1 box art required, 2:3 poster art recommended.
- MSI/EXE package URL must be HTTPS, versioned, stable, and must point to a signed standalone installer.
